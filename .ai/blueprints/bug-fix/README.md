# bug-fix

Fix a defect at the owning layer with a regression test that fails before the fix. In the sandbox this is an `edit-module` session whose brief describes a symptom; at the repository root it is `.ai/skills/bug-hunt/SKILL.md` followed by a pull request. A defect in `packages/**` switches to `core-extend` for the paths and gates, and keeps this blueprint's steps.

No behaviour beyond the fix travels in the change: no refactors, no renames, no reformatting of untouched code.
