# README artwork

Created with the built-in image generation tool using the approved Flowdular OG as a style and brand reference. Both selected outputs were visually inspected.

- `flowdular-readme-banner.png`: README opening banner; retains the woven # mark.
- `flowdular-readme-modules.png`: decorative overview of modules, agents and workflows.

## Banner prompt

Use case: ads-marketing. The attached image is a style and brand reference. Create a new wide GitHub README header banner, aspect ratio 3:1. Same premium dark navy and warm orange tactile 3D visual language. Left two thirds: the exact existing white/orange woven hash # logo from the reference beside a very large crisp white "Flowdular". Below in smaller clean typography exactly "Build your business platform." Right third: a compact sculptural assembly of navy rounded-square modules linked by warm orange paths, one orange module, precise material and soft studio lighting. Generous margins, excellent legibility at 830px wide. Preserve the reference # logo shape exactly, with its same interlaced bars and gaps. No additional text, no badges, no frame, no fake UI, no neon, no cropped content. Full bleed navy background. Beautiful restrained software branding.

## Modules prompt

Use case: ads-marketing. The attached image is a style reference for a matching GitHub README illustration. Create a wide 2.5:1 panoramic illustration in the same premium navy/orange tactile 3D style. Three equal groups arranged left to right on dark navy: first a neat cluster of three modular rounded square navy building blocks with one orange edge, second a single orange central agent tile with a simple white four-point spark engraved into its face connected to two smaller navy tiles, third three navy rounded tiles joined by orange paths in a branching workflow with one orange end tile. Warm studio lighting, precise matte surfaces, subtle depth, calm composition and generous negative space. Under each group put one clearly legible clean white label, exactly "Modules", "Agents", "Workflows". These are the only text. Do not include a brand logo or wordmark in this secondary illustration. No robot faces, no extra labels, no fake application screens, no arbitrary wires, no neon or purple. Full bleed navy background, keep everything inside generous margins, balanced modular composition that remains legible at GitHub README width.
