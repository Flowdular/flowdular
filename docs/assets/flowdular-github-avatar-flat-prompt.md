# Flat GitHub avatar

Built-in imagegen, edit mode. Output: `flowdular-github-avatar.png`.
Replaces the previous 3D avatar with flat woven bars on navy. Visually inspected.

## Prompt

Edit the supplied Flowdular avatar into strictly flat vector-style artwork. Preserve the exact existing woven hash # silhouette, interlace gaps, rounded ends, placement, size and square canvas. Two vertical strands are solid ivory white #FFFFFF, two horizontal strands solid warm orange #F59B3D. Background solid dark navy #0B1526. Remove ALL 3D extrusion, bevels, shadows, gradients, textures, highlights, lighting and perspective. Every shape must have one perfectly uniform flat color with clean crisp edges. No text, no extra objects, no outline. Centered symbol with the same generous padding. This must look like a clean flat SVG logo rasterized to PNG, not a rendered object.
