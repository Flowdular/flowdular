# UI pass on narrow windows, tables and drawers, 2026-09-17

## Scope and evidence

A headless Chrome pass over main at 88519c2 with the local demo data, signed
in as the demo owner, at 1440 and 900 px windows, in English and with the
workspace default locale set to Polish. It covered sign in and the SSO screen,
the dashboard, Modules, Audit, Documents (with an uploaded CSV and its Text
tab), Research with its adapter drawer, Data adapters, Templates, Users and
Settings, and the context rail collapse. "After" readings come from the same
pass against this branch on its own local instance.

Plural forms and the Polish copy gaps found in the same pass are fixed in a
separate change. The lowercase DOM property names (`maxlength`,
`autocomplete` and the rest) outside `@flowdular/ui` are a follow-up.

## Findings and fixes

- **Narrow windows.** At 900 px the sidebar (260 px) and the context rail
  (220 px) left the workspace 420 px, so Audit scrolled sideways and the
  breadcrumb lost the page name. Below 1200 px the sidebar now starts as its
  icon rail and below 960 px the context rail as its strip; either toggle opens
  the full panel over the workspace, a click beside it or a navigation closes
  it, and the stored preference is left alone. After: the workspace is 812 px
  at 900 and 820 px at 1100, and widening back to 1440 restores the stored
  layout.
- **Topbar.** The group in the breadcrumb gives way before the page name, and
  below a 560 px topbar the search shrinks to its icon with the label as its
  accessible name.
- **Column hiding.** A whole priority hid at once, so Modules at 1440 (a
  902 px card) showed only Module and Status. Columns now hide one at a time,
  priority 3 before 2 and the last declared first, each at its own container
  step. After: Module, Version and Status in English, and Module, Version,
  Dependents and Status in Polish at 1440 with the sidebar folded.
- **Empty and loading tables.** The placeholder cell spanned hidden columns,
  so the table grew columns its header did not cover (Data adapters, Documents
  and Templates when empty). It now spans the columns that never hide and its
  content is as wide as the card. After: the Data adapters header spans the
  card.
- **Action column.** Polish labels ("Dezaktywuj") were cut by the declared
  236 px column. The column now grows to its widest measured row of buttons.
  After: 238 px in Polish, every button whole.
- **Drawer padding.** The research adapter drawer had its fields against both
  edges and its Run test button cut. The research adapter and query attempts
  drawers, the data adapter binding and runs drawers and the import job drawer
  put their content straight into `ui-drawer__body`, which has no padding; they
  now wrap it in `ui-form` like the other drawers.
- **Dashboard activity.** A workspace with events on one day showed "No
  activity yet"; the chart now shows whenever any day has an event.
- **Search placeholders.** A search in a card head shrank to about 120 px
  ("Search acto"); it now keeps 200 px and the head wraps instead.
- **SSO screen.** The field hint repeated the description and the unknown
  workspace error sat above Continue while the no SSO notice sat below; the
  hint is gone and both results show below the button.
- **Documents scan column.** "Nieskanowany" was cut at 130 px; the column is
  150 px.
- **`tabindex`.** Octane warned "Invalid DOM property `tabindex`" on every page
  with tabs or a More menu. The shared components use `tabIndex`,
  `maxLength` and `spellCheck`; no warning appeared in the after pass. The
  warning fires only for dynamic values in a dev build, so the unit tests
  cannot observe it; a static check comes with the module sweep.

## Checks

`pnpm verify:static` passes. Unit tests cover the per column steps
(`packages/ui/tests/table-layout.test.ts`), the hide and reveal classes, the
placeholder span and the measured action width
(`table-narrow-render.test.tsrx`), the shell fold decisions
(`packages/client/tests/shell-layout.test.ts`) and the one day activity chart
(`overview-charts.test.tsrx`). The placeholder span, action width and activity
tests fail on main.

## Remaining risks

- The action width is measured after render, so the first frame of a table
  with longer labels still uses the declared width.
- A click in the same frame as a resize across 1200 px can act on the previous
  layout and store the preference.
